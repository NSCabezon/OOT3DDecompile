## Learned about 3DS code (add as you learn)
- `Actor` is 0x1A4 bytes (N64 0x14C) → actor-specific fields shifted +0x58 vs N64.
- Init often starts with `actor.unk_19A = 1` (not in N64).
- Many actors' action functions are NOT in the actor dir: they are `FUN_xxxxxxxx` in `src/functions/functions_*.cpp`.
- Some N64 actors are empty stubs on 3DS (`bx lr` ×4): En_Horse_Ganon, En_Horse_Zelda, En_Sda (Link's shadow moved elsewhere).
- Display lists → models: `FUN_00372f38(actor, play, &skelAnimModel, idx, 0)` loads a model, `FUN_00350f34` frees it (En_Tana).
- Data in C: arrays defined BEFORE `<Actor>_InitVars` get placed ahead of it by the linker and break matching → define them after InitVars.
- `ACTOR_FLAG_0` etc. not defined in repo headers; use literals.
- Debug prints / debug draw are stripped.
- Timers scaled by `R_UPDATE_RATE`; `Actor_Spawn` has an extra arg; some N64 statics live in PlayState.
- Matching tricks: access base fields via the `Actor* actor` param instead of `self->actor`; declaration order of locals (`play` before `self`) changes registers; float compares vs constants may compile to integer compares of raw bits.
- **Register-swap fix:** declare Init/Destroy/Update as `(MyActor* self, PlayState* play)` and cast to `(ActorFunc)` in InitVars (instead of `(Actor*, GameState*)` + casts). Or write the casts inline in the call. Fixed Door_Toki, Bg_Mizu_Uzu.
- DynaPoly actors: `ReadCollisionHeaderFromZsi(DynaPolyInfo_Alloc(&dyna, play, n), &colHeader)`; `unk_19A = 1` after `DynaPolyActor_Init`. `DynaPoly_DisableCollision` = `FUN_0036b940`, `DynaPoly_EnableCollision` = `FUN_0036d15c`.
- Some speeds are scaled ~2/3 vs N64 (30→20 fps logic?): Bg_Mizu_Uzu rotation 0x1C0 → 0x12B. Not always (En_Arow_Trap timer 80 unchanged).
- `Player` struct lacks many fields: use raw offsets (e.g. currentBoots at +0x1A7) until struct is filled.
- Merge with `scripts/merge_ws.py <A>` (copies actor dir, removes GLOBAL_ASM lines the agent deleted from functions_*.cpp, warns on anything else).
- `CollisionCheckInfoInit2` is 0xC bytes on 3DS (N64 0xA): extra `s16` = -1 at +0xA. Repo header has N64 layout → wrap locally `{ CollisionCheckInfoInit2 base; s16 unk_0A; }` (En_It).
- Data-before-InitVars rule isn't universal (En_It matched either way) — just check data bytes.
- Real prototypes: `FUN_00372f38(actor, play, &skel, idx, &skel2, idx2, 0)` (7 args, loads up to 2 models); `FUN_00350f34(actor, &skel, &skel2, 0)` (4 args). The 5/3-arg decls in `include/functions.hpp` are truncated.
- armlink `--inline` turns calls to empty C functions in OTHER files into `mov r0, r0` but keeps arg setup (e.g. N64 `Actor_SetObjectDependency`). Reproduce by calling an empty C-compiled function from another file (Bg_Haka_Megane uses `GraphicsContext_UnknownStub`).
- PlayState raw offsets: `roomCtx.curRoom.lensMode` = +0x4C35, `actorCtx.lensActive` = +0x208F.
- `__attribute__((used)) static` needed for data arrays only referenced by still-asm functions (else armcc drops them).
- Switch with ROM `cmp #K; beq; nop; ble default` then linear tests = explicit `if (x == K) goto A; else if (x <= K) goto def;` before a normal switch, with the switch var in its own `{}` block (Bg_Spot16_Doughnut Init).
- Float scheduling (two loads into same s-reg): compute diffs into a `Vec3f d` temp, then copy to `dx`/`dz` locals (En_Nwc Idle).
- Store via `s16* p = &self->field; *p = v;` in an inline helper gives ROM `mov r0,#off; strh rX,[r0,r4]` instead of a shared `add rN,r4,#0x300` base (Demo_Du Init; also DemoSa_Init, caseD_9_003858a0).
- `play2` param pattern: passing `play2` (the raw param) to ONE callee and `play` elsewhere shifts regs (ldrb r1/bic, compare r1/r2) — Bg_Bombwall FUN_003f5a3c. Helper taking `Actor* thisx` + cast inside gives `bic r1,r0` / extra `mov r8,r4` (Bg_Bombwall Init).
- Extra pointer copy in a callee-saved reg (ROM `mov r5,r4`): add a 2nd typed local `Self* s2 = self;` used in only one call (Bg_Jya_1flift Init). Tail call that armcc inlines: move callee definition to a separate .cpp in the actor dir (no noinline).
- Shared static model loader SOLVED (2026-10-13): `include/model_manager.hpp` `GetModelManager()` inline accessor (function-local static → COMDAT .data/.bss pinned in data/oot3d.ld). Recipe: `notes/LOADER_RECIPE.md` (multiple uses: one scoped `ModelManager& mm = GetModelManager();` per use). Call site: `ModelAllocator* alloc = GetModelManager().allocator; alloc->owner = owner; model = alloc->Create(cmb, 1); alloc->owner = NULL;`. Per-actor local statics with guard (En_Hs2 PostLimbDraw): same method via a plain `inline` accessor + pin + data-chunk split. Debt: src/data/data_54AC28.s is a trimmed copy (proper fix: split in disassembly/data_chunks.txt + regen).
